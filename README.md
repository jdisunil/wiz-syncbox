# wiz-syncbox
# WiZ Sync Box — Phase 1

Free camera-based colour detection prototype for iPhone Safari. No Philips WiZ control is implemented yet.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `wiz-syncbox`.
2. Upload `index.html` to the root of the repository and commit.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**.
5. Wait for the HTTPS Pages URL: `https://YOUR-USERNAME.github.io/wiz-syncbox/`.
6. Open it on iPhone 13 in Safari, tap **Start camera**, and allow camera access.
7. Point the rear camera at the TV and verify that colour swatches change with the picture.

Video frames are processed locally in Safari and are not uploaded. This prototype does not control lights. GitHub Pages is a public website, so do not upload secrets, device IP addresses, or credentials.
